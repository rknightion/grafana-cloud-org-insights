###   BREAKING CHANGES

* **maturity:** replace cardinality_discipline with the labelling score
* bin/alerts.py has a new rule key, fleet_fast_scrape. A deployment that sets GCINSIGHT_ALERT_RULE_UIDS_JSON must add a fleet_fast_scrape entry (default uid gcinsight-fleet-fast-scrape) or the alerts tool refuses to start with "keys differ". The scan runtime projection also gains GCINSIGHT_FLEET_DEFAULT_SCRAPE_INTERVAL (Terraform fleet_default_scrape_interval, default 60s), so a consumer that pins GCINSIGHT_RUNTIME_CONFIG_DIGEST must regenerate it after upgrading.
